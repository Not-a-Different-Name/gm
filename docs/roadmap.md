# 实施路线图

## 第一阶段：可验证基础

建立工作区、代码规范、确定性随机源、区块坐标、世界元数据、方块注册、种子与存档模型。验收条件是逻辑可测试、可构建，且相同种子结果一致。

## 第二阶段：单机可玩世界

已完成种子地形、区块数据和浏览器端基础网格预览：包含草地、泥土、石头、沙子、基岩和静态水。下一步实现树木、固定世界边界、按视距加载、IndexedDB 存档及可替换的材质图集。

## 第三阶段：玩家交互

实现第一/第三人称、移动、跳跃、飞行、方块选择、破坏和放置，及采用方块颜色的粒子反馈。没有伤害和生存数值。当前已完成鼠标视角、WASD 移动、基础方块碰撞、跳跃、飞行和第一/第三人称切换；接下来实现射线选中、放置/破坏和粒子。

## 第四阶段：模组与联机

提供本地模组加载、版本及哈希校验、模组 API；搭建两个房间以内的 WebSocket 服务、房间存档和附近区块增量同步。

## 第五阶段：玩法扩展

逐步开放配方、熔炉、实体、更多液体交互、UI 扩展和性能优化。合成功能应由模组能力实现，而不是把规则硬编码到本体。

## 已记录的后续改进

在当前方块交互、存档和模组基础完成后，依次实现：方块纹理图集与可模组替换材质、水下视角效果、入水后的移动与物理反馈，以及树叶方块的实体碰撞。这些项目会保持为独立渲染或方块属性扩展，避免影响世界生成和存档兼容性。

水体透明材质、水下雾与移动效果、天空渐变和像素云层也是该阶段的必做项；它们与基础纹理图集分开实现，以便独立调节性能与画面风格。天空渐变、方块日月、星点与昼夜光照已经完成（见 `packages/renderer/src/sky.ts`），像素云层与水体相关效果仍待补充。

水流扩散是已列为必做的确定性世界模拟：加入流动时要让横向扩散范围明显低于经典沙盒，避免一小片水淹没大面积地形。它必须放在 `packages/core` 并由种子/状态确定性驱动，附单元测试，且需评估对被修改区块增量存档的影响。详见[项目交接](project-handoff.md)第 2 节第 5 点。
