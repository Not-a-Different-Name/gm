# 本地世界存档

## 存储位置

单机世界使用浏览器的 IndexedDB，数据库名为 `gm-worlds`，存储表为 `worlds`。每个世界以种子文本作为 ID；相同种子会打开同一份本地存档，不同种子互不影响。

## 保存内容

存档保存世界元数据、玩家坐标和被玩家改动的区块方块差异。基础地形、海水和树木不写入 IndexedDB，因为它们能够由种子和生成器版本重新生成。每次方块放置或破坏后约 600 毫秒写入一次，连续操作会合并为一次保存。

## 恢复过程

打开世界时，游戏先用种子生成区块，然后把保存的差异覆盖到对应区块，最后恢复玩家位置。差异区块使用本地索引和方块 ID 表示，体积远小于完整区块，适合无限地图的长期保存。

## 当前限制

当前版本不提供存档列表、导出、删除或跨浏览器同步；清除浏览器站点数据会删除本地世界。服务器持久化会在联机阶段使用兼容的“世界元数据 + 区块差异”模型，但不会直接访问浏览器 IndexedDB。
