# 地形与渲染设计

## 本阶段范围

本阶段让浏览器能从世界种子生成并显示一片真实方块地形。它不包含玩家控制、破坏/放置、水流、存档或联网；这些功能会在后续阶段在现有边界上接入。

## 地形生成

`TerrainGenerator` 是纯确定性模块：输入世界种子和区块坐标，输出同一个 `16 × 16 × 256` 区块。它不读取网络、文件、当前时间或浏览器状态，因此客户端和未来服务器能在相同版本下独立得出一致地形。

地形高度由三个不同尺度的平滑值噪声叠加：大尺度大陆（220 方块）、丘陵（72 方块）和局部细节（28 方块）。高度限制为 24 至 142，以产生比经典默认地形更大的起伏，同时留下足够的垂直空间供未来结构和玩法使用。

当前层次从下到上为：基岩、石头、三层土壤和草方块；低于海平面的地表改为沙子，并填充静态水。符合地面条件的区域会生成较大的确定性树木；树干和树叶可跨越区块边界，但生成结果不依赖区块加载顺序。矿物和洞穴尚未接入，符合当前“不生成矿物”的范围。水已作为方块生成，但其扩散与更新规则会在方块交互阶段实现。

## 区块数据

一个 `Chunk` 使用 `Uint8Array` 保存方块 ID，单个区块约 64 KiB。这比对象数组轻得多，也容易在未来序列化成修改区块增量。数组布局和区块坐标换算都在 `@gm/core` 中，渲染层不能直接修改它。

无限世界由按需生成的区块缓存构成；固定世界复用同一生成器，只在查询或加载前检查 `WorldBoundary`。当前预览加载中心周围 `3 × 3` 个可见区块。默认是无限地图预览；在网址后加 `?world=fixed` 可切换为固定边界测试，`?seed=任意文本` 可指定种子。为了正确消除区块边缘的内部面，渲染时可能读取相邻区块，但不会把这些额外区块加入画面。

## 网格与性能

渲染层仅为不透明方块生成与空气或透明方块相邻的面，内部面不会上传到 GPU。每个面用顶点颜色模拟方向光照，因此当前无需纹理资源，也能清楚显示方块层次。水单独生成透明网格，方便后续替换为流动材质。

这是可验证的基础网格实现，尚未使用贪心网格合并。玩家移动和视距动态加载加入后，将优先升级为合并面网格、分帧构建和可配置的低/中/高视距，避免在性能较弱的设备上一次性重建过多区块。

## 材质与模组衔接

当前 `BLOCK_DEFINITIONS` 已集中保存每个方块的 ID、透明性、碰撞语义与临时颜色。渲染器通过此注册表取色，不在网格代码中硬编码具体方块。未来模组 API 会把颜色替换或扩展为材质引用、纹理图集和着色器参数，因此本阶段的顶点色不会锁死后续美术方案。
